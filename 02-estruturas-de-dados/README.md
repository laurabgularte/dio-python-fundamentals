# Módulo 02: Estruturas de Dados em Python

Focado no domínio das coleções nativas de Python e na manipulação eficiente de dados em memória.

## 📂 Conteúdos Abordados

- **Listas (`list`):** Métodos de inserção, remoção, ordenação e compreensão de listas (_list comprehensions_).
- **Tuplas (`tuple`):** Imutabilidade e utilização prática.
- **Conjuntos (`set`):** Operações matemáticas de conjuntos (união, interseção, diferença) e eliminação de duplicados.
- **Dicionários (`dict`):** Estruturas chave-valor, iteração e métodos de manipulação de dados associativos.
