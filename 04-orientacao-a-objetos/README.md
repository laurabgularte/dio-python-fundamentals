# Módulo 04: Programação Orientada a Objetos (POO)

Aborda os pilares da modelagem orientada a objetos aplicada em Python para estruturar sistemas robustos e escaláveis.

## 📂 Conteúdos Abordados

- Classes, instâncias, construtores (`__init__`) e destrutores.
- Os quatro pilares da POO:
  - **Encapsulamento:** Propriedades públicas, privadas e métodos de acesso.
  - **Herança:** Simples e múltipla, reutilização de código e método `super()`.
  - **Polimorfismo:** Sobrescrita de métodos e comportamento dinâmico.
  - **Abstração:** Classes abstratas (`abc` module).
- Métodos de classe (`@classmethod`) e métodos estáticos (`@staticmethod`).
