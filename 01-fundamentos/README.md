# Módulo 01: Fundamentos de Python

Este diretório armazena os códigos e anotações referentes aos conceitos basilares da linguagem Python desenvolvidos durante a formação da DIO.

## 📂 Conteúdos Abordados

- Sintaxe básica e indentação.
- Variáveis, constantes e atribuição de valores.
- Tipos de dados primitivos (`int`, `float`, `str`, `bool`).
- Operadores aritméticos, de atribuição, comparação e lógicos.
- Estruturas condicionais (`if`, `elif`, `else`) e de repetição (`for`, `while`).
